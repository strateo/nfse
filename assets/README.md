# Project icon

`icon.svg` is the editable project mark; `icon.png` is its 512px raster companion
for README and sharing use. The mark combines an invoice outline with a
process line and square node, using Strateo's petroleum `#104A58`, warm cream
`#F5F2E9`, and structural sage `#9DB5B2`. It is a project illustration, not the
Strateo wordmark or the official government NFS-e logo.

No fonts, third-party icon paths, remote assets, filters or scripts are embedded.
