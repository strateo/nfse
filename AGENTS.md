# nfs-api

Python 3.11+ client library `nfse_nacional` for the NFS-e Padrão Nacional (SEFIN Nacional + ADN).

## Commands

- Setup: `python -m venv .venv` then `.venv/Scripts/python -m pip install -e .`
- Tests: `.venv/Scripts/python -W error::ResourceWarning -m unittest discover -s tests`. Tests use stdlib unittest, a throwaway PKI (`tests/_certs.py`) and a local mTLS server. No network access.

## Structure

- `src/nfse_nacional/`:
  - `environment.py`: URLs and the DPS `Layout` per environment.
  - `documents.py`: CPF/CNPJ (alphanumeric) and Ids.
  - `dps.py`: model, builder and offline rules.
  - `events.py`: pedRegEvento builders.
  - `signing.py`: XMLDSig and wire serialization.
  - `schemas.py`: XSD validation.
  - `certificate.py`: PFX and mTLS context.
  - `client.py`: SEFIN and ADN clients.
  - `danfse.py`: DANFSe PDF (NT 008), using reportlab.
  - `errors.py`: exceptions and error-body parsing.
- `src/nfse_nacional/schemas/{producao,producao_restrita}/`: official XSD bundles, copied unmodified from gov.br. Never hand-edit them. Upstream defects are patched at load time in `schemas.py`.
- `src/nfse_nacional/data/`: Anexo A municipality/country tables and the official NFS-e logo, generated by `scripts/build_reference_data.py`. Regenerate them; do not edit them by hand.
- Private integration modules and internal business research are excluded. Public, source-backed fiscal research is in `docs/research/`.

## Conventions

- Dataclass fields that map 1:1 to XML elements use the official tag names (`cTribNac`, `pAliq`), so each value traces to Anexo I. Everything else is English.
- Every layout difference between `Layout.V1_01` (production) and `Layout.NT009` (Produção Restrita) goes through the `layout` branches in `dps.py`. Both layouts must stay covered by `tests/test_dps.py`.
- Offline guards in `dps._validate` cite the SEFIN E-code they prevent. Add a guard only for rules confirmed by an official source or by several implementations.
- Amounts are `Decimal`; never round silently.

## Updating the schemas

1. Download the new zip from gov.br "Documentação Atual" (production) or "Produção Restrita".
2. Replace the matching folder.
3. Run the tests. Remove the `TSSerieDPS` resolver patch in `schemas.py` once the production bundle no longer contains `^0{0,4}\d{1,5}$`.
